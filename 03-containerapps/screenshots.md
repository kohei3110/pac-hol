# 第3回 — 画面と図の出典・更新方法

Portalやアプリを撮影した画像と、説明用に描いた図は、出典を分けて記録します。
画像の種類、撮影日、状態、隠した範囲、出典、寸法、SHA-256は `assets/manifest.json` に保存しています。

Azure上のアプリ画面を追加するときは `assets/app/` に置き、`deployed-app-browser-screenshot` と記録します。Portalのリビジョン管理画面とは別の画像です。
画面の値を学習用のものに合成することはしません。
今回は、両版のトップページが同じHello Worldだったので、その2枚では版を見分けられませんでした。代わりに、実際のAPI応答から識別値を抜き出した図を載せています。これは撮影した画面ではありません。

2026-10-12に作成フォームの5枚を追加撮影しました。環境とアプリの「作成」は実行しておらず、既存のアプリやトラフィックは変更していません。
イメージ・変数・ポートの入力位置は見られますが、作成後のリビジョン管理、preview、100%切り替えの画像ではありません。
アカウント・契約の欄は切り出しから除き、入力値の合成もしていません。

## 配布前に撮っておく画面

| 番号 | 画面 | 必ず見せること |
| --- | --- | --- |
| 02 | 開催用の環境設定全体 | 名前・リージョンも含め、通し実施の設定が揃っていること |
| 03 | 開催用の作成前の最終確認 | イメージ・変数・小型設定・ターゲット80・HTTPSのまとめ |
| 04 | 初回デプロイ完了 | アプリ・環境の作成成功 |
| 05 | 旧版の版確認 | 旧版の版とリビジョン名。全環境変数を撮らない |
| 06 | Multipleと旧版固定 | Multiple、具体名の旧版100%、Latestなし |
| 07 | 新版作成 | 新版タグ・変数、v2、旧版を変更していないこと |
| 08 | 新版0%とpreview | Active新版0%、ラベル、共通URLは旧版 |
| 09 | 新版100%と実応答 | 割合と共通URLの新版 |
| 10 | 切戻し100%と実応答 | 旧版割合と同じ共通URLの旧版 |
| 11 | 削除確認 | 自分のRGと今回のアプリ・環境だけ |
| 12 | 削除完了 | 更新後のRG・アプリ・環境一覧で該当なし |

未撮影の画面は、manifestの `pendingScreenshots` に残します。CLIでできた操作も、Portalで試してから撮影してください。
Microsoft Learnの画像を参照するときは、公式資料からの引用と分かるように出典を書きます。

## 撮影・マスク

撮影用のウィンドウだけを写します。アカウント、契約、業務用リソース、実際のID、URL、不要なIP、個人情報は不透明な矩形で隠し、PNGのメタデータも除去します。
`/api/env` の全応答、鍵、トークンは撮影・提出しないでください。元画像はローカルの一時領域に置き、公開用画像の確認後に削除します。

公式アイコンの切り抜き・変形・色変更はしません。
MCRは、今回作るAzure Container Registryのリソースではないので、ACRのアイコンを置かず文字で示しています。

## 再生成と再実施

ルートで `python3 tools/build_handson.py --lesson 03` を実行し、図と画像入りHTMLを作ります。
PDFも、HTMLの「手順書を印刷・PDF保存」から作り直してください。第3回だけを更新する場合、第1・2回のファイルを作り直す必要はありません。
HTMLの画像はクリックまたはEnterで拡大できます。

手順を変えたら、旧版固定 → 新版preview → 新版100% → 旧版100% → 削除まで試します。
同じタグでもイメージの中身が変わることがあるので、開催前にはMCRで取得できるかとダイジェストを調べ、`assets/sample-images.json` と照合してください。
変わっていれば、以前と同じ版だと判断せず、手順と実際の応答を試し直します。
