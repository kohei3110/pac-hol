## 2026-11-09 — OSディスクをStandard SSDへ変更（教材更新）

参加者手順と講師用資料のOSディスクを**Standard SSD LRS**へ変更しました。検証用としてStandard SSDを使うことと、本番環境では読み書き性能や応答速度を重視してPremium SSDがよく使われることを説明しています。本番用は必要な性能と費用に応じて選び、この実習ではPremium SSDには変更しません。

この更新ではAzureへの再デプロイは行っていません。以下の2026-11-02の実機確認は**Standard HDD LRS**で実施した記録です。過去の実機検証JSONと教材のファイルハッシュは当時の証拠として保持し、Standard SSDでの実機検証結果とは扱いません。

### 見つかった不備と修正

公開IPのゾーン設定は、実際に作成を止める不備でした。BasicをStandardへ変えたり、CLIで作成を代行したりせず、本文に公開IP作成ペインの設定と失敗時の確認方法を追加しました。
日本語PortalでもBastionは英語表示で、認証の既定値はMicrosoft Entra IDでした。実際の選択肢Private Key from Local File、Username、Browse、SSH Passphraseと、不要なEntra設定を行わない説明を加えました。
VNetのアドレス入力、プライベートサブネットのオン／オフ、NSGまでの経路、キー保存のボタン、VM停止の「はい」、RG削除の2回目の確認も実画面に合わせました。
タグは名前と値を分け、入力後に3行を見直します。作成直後のRGが候補に出ない場合の更新方法と、HDD廃止予定の警告も説明しました。
削除後のディスク検索では、一覧ではなくストレージ センターの要約が開きました。リソースタブへ移動し、読み込み終了と0/0を確認する手順を加えました。RGの削除には約13分かかりました。5〜15分は目安であり、時間の経過だけで完了と判断しないよう明記しました。

HTMLでは、短い画面で固定目次の下にあるチェック解除ボタンへ到達できない問題を修正しました。
PDFでは、長い日本語の内部IDによる名前の長さの警告を解消し、共通の始め方と折りたたみの解答例も印刷します。本文の更新に合わせてHTML・PDFを再生成します。
Task別の目安だけで74〜99分かかるため、全体を90〜120分＋予備15分に修正しました。実際の初学者の時間は、開催前に別途測る必要があります。

接続後の結果は`assets/portal/08-bastion-commands.png`に収録しました。これは今回の実画面の切り出しで、結果の文字列は描き替えていません。
今回の構成・初回失敗と復旧・接続・削除の証拠は`assets/portal-validation-2026-11-02.json`、2026-11-02時点の教材の内容一致・表示・印刷・ファイルハッシュは`assets/materials-validation-2026-11-02.json`に分けて記録しています。サブスクリプションID、実IP、認証URL、秘密鍵は公開証拠に含めていません。
作業後、今回の秘密鍵・事前検証用の鍵・加工前画像を削除し、認証済みの専用検証ブラウザーも停止してプロファイルを削除しました。通常のブラウザープロファイルや、他の実習の鍵には触れていません。

## Azureで試した結果

新しく作った検証専用RGで、Ubuntu 24.04 x64 Gen2のB1s VMとBastion Basicを作成しました。
VMには公開IPを付けず、Bastion用にはStandard・静的のIPv4公開IPを1つ使用しました。
専用/26サブネットとVM用/24サブネット、VM側の300／310規則、実効NSG、RSA PEM形式を確認しました。
VMは実行中になり、割り当て解除後もOSディスクとBastionが残りました。

最後に検証用の専用RGだけを削除し、同じサブスクリプションに残っていないことを確かめました。
30項目をすべて確認した実行時間は、約24分41秒です。CLIでの準備と片付けの時間で、参加者の所要時間や料金を測った結果ではありません。
Network Watcherは増えておらず、既存のAzureリソース・ネットワーク・ポリシーも変更していません。
使った秘密鍵と加工前のPortal画像は、作業後に削除しています。

未確認なのは、PortalでのVM作成完了、ブラウザーSSHログイン、VM内の3コマンド、Portalの削除画面と各一覧、初学者による実施です。
そのため、実機記録の `fullHandsOnPassed` は `false`、`bastionLogin` は `not-executed` のままです。
